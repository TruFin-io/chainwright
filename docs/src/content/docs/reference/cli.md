The full surface of the `chainwright` binary.

## Usage

```bash
chainwright <setup-dir> [options]
```

## Arguments

| Argument      | Description                                  |
|---------------|----------------------------------------------|
| `<setup-dir>` | Path to the wallet setup directory.          |

## Options

| Flag             | Description                          |
|------------------|--------------------------------------|
| `-f, --force`    | Rebuild cached profiles.             |
| `--wallets`      | Filter to specific wallets.          |
| `--all`          | Build profiles for every wallet.     |
| `-h, --help`     | Print usage.                         |
