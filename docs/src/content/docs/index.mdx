## What is Chainwright?

Chainwright is an end-to-end testing framework for dApps, built on top of Playwright. It enables seamless testing of multi-chain dApps by supporting multiple wallets across the EVM, Cosmos, Aptos, and Solana ecosystems.

## Why Chainwright?

Chainwright is an end-to-end testing framework built to meet your web3 development needs.
