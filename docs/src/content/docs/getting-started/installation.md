How to install `chainwright` into a project.

## Prerequisites

- Node.js
- A test runner (Playwright recommended)

## Install

```bash
# bun
bun add -d chainwright

# pnpm
pnpm add -D chainwright

# npm
npm install -D chainwright
```

## Verify

```bash
npx chainwright --help
```
